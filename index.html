AI Engineering: Intelligent Monitoring of UiPath Robots

Talan Tunisia · Tunis, Tunisia

Built an end-to-end AI monitoring system for UiPath robots that cut LLM token volume by 86% and reached an 88.9% F1-score on real-world runs: a 4-node LangGraph pipeline, a full-stack app, a conversational assistant and Microsoft Teams alerts.

  • Designed a LangGraph pipeline that orchestrates 4 specialised nodes: RAG cache, LLM Analyzer, Evaluator and Remediator.
  • Implemented semantic compression of UiPath logs before sending them to LLaMA 3.3 70B, with anti-hallucination validation of the evidence.
  • Developed a FastAPI–PostgreSQL backend, a React/TypeScript interface, a WebSocket conversational assistant (LLaMA 3.1 8B) and automated Microsoft Teams notifications.
  • Implemented a continuous-learning loop that enriches the knowledge base from N2 technician feedback.

Impact: Semantic compression cut token volume by 86%, and the system reached an 88.9% F1-score on 35 real-world runs evaluated by experts, with a latency gain from the semantic RAG cache.
